# music-portfolio
The music I've composed/arranged.

## Compositions
### Hanafueda
A card battler inspired by _Balatro_ and the traditional Japanese card game Hanafuda. The 8-bit soundtrack was created to match the pixel art style of the game.

### Wicket
An adventure game based on Welsh folklore and mythology. Most of the pieces are steeped in Welsh folk tradition while "Codi Niwl Cau Hyd y Nen" is an avant-garde track utilizing traditional Welsh instruments.
